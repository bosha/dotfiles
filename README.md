# dotfiles

A collection of configuration files from my home directory—files that aren’t as extensive as, for example, Neovim, so they don’t warrant a dedicated repository.

I use MacOS, so the configuration may not be compatible with Linux.

## Configuration files

| Filename | Description |
| --- | --- |
| `.wezterm.lua` | Small wezterm configuration with automatic light\dark theme switching based on the current macos theme.  |
| `.config/yazi` (directory) | Yazi configuration files. Run `ya pkg install` after clonning the repository.  |
